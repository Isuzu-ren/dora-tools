# 10-水体与淹没

本域只有 3 件，但都是水旱业务的主指标：淹没范围、水域面积、应急航拍水体。
三件全部依赖模型权重，且全部落在 B/C 档——这正是「业务主干需要改造或重训」的直接体现。

配套的能力不在这里：洪水面积与水量在栅格分析 / 计算与决策域（`ras.threshold`、`ras.area`、
`calc.volume`），其中 `ras.threshold` 做 SAR 后向散射阈值，是不需要任何权重的下限基线（IoU 0.267）。

## 工具速查（3 件）

| 工具 | 相关性 | 可迁移性 | 用途 |
|---|---|---|---|
| [`seg.flood`](seg.flood.md) | ★★★ | C（跨分辨率失效） | 洪水淹没范围主入口；两次水体推理再相减 |
| [`seg.reservoir`](seg.reservoir.md) | ★★★ | C（14 波段归一化） | 干旱核心：水域面积萎缩监测；需 14 波段输入 |
| [`seg.water_aerial`](seg.water_aerial.md) | ★★★ | C（0.03 m 航拍） | 应急航拍精细淹没边界 |

## 相关但不在本域

- `ras.threshold`（40-栅格分析）：SAR 阈值法，零权重基线
- `ras.area` / `calc.volume`（40 / 60）：面积与蓄水量
- `vis.overlay_mask`（70-制图与报告）：淹没范围压底图

## 列的含义

- **相关性**：★★★ 业务直接调用 / ★★ 流程必需 / ★ 特定子场景 / ○ 无交集
- **可迁移性**：A 零改造直迁 / B 加规范可用 / C 必须重训 / D 不建议迁
- 判定依据见 [`01-工具全景`](../01-工具全景.md) 与 [`99-附录/A-接入红线`](../99-附录/A-接入红线.md)
